Шифрование данных дашборда

Страница работает локально: ничего никуда не отправляется, шифрование идёт в вашем браузере. Пароль в файл не попадает — из него выводится только ключ. Эту утилиту не нужно открывать с сайта, достаточно открыть файл с диска.

1. Данные

Вставьте JSON по контракту из README или нажмите «Демо-набор», чтобы посмотреть формат.

2. Логин и пароль

Эта пара — единственный способ открыть данные. Забудете — восстановить нечем, придётся пересобрать файл заново. Пароль берите длинный: репозиторий публичный, значит шифротекст доступен для офлайнового перебора.

3. Результат

Готовый файл положить в репозиторий по пути data/dashboard.enc.js, заменив прежний.

Проверка

Расшифровать только что собранный файл тем же логином и паролем — убедиться, что он открывается.
